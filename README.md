# Casa 01 · Estudo de melhorias

Maquete 3D esquemática e orçamento editável das melhorias estudadas para a casa.

## [▶ Abrir o projeto](https://ganseblumchen97.github.io/estudo-casa-3d/?v=17)

Tudo fica nessa página: a maquete 3D, a troca das opções (piscina, carro, escritório, grade) e o orçamento, que gera o PDF.

### Como usar o orçamento

1. Desça até **Orçamento**, ou clique em **Orçamento** na barra do topo. Ele já vem com os itens da configuração escolhida.
2. Ajuste quantidades e preços, ou use **+ Adicionar item** para incluir materiais e serviços (escolha da lista ou escreva).
3. Preencha responsável, data, BDI e observações.
4. Marque **Com imagem da maquete** se quiser a imagem no PDF (para imprimir, deixe desmarcado).
5. Clique em **Gerar PDF** e escolha **Salvar como PDF**.
6. Para devolver uma versão que ainda pode ser editada, use **Salvar arquivo**; quem receber abre com **Abrir arquivo**.

O que é digitado fica salvo só no navegador de quem está usando.
