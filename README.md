# Estudo da casa em 3D

Maquete 3D esquemática com as opções de melhorias estudadas para a casa: grade anti-fuga de gato nos fundos, cobertura do carro, lavação fechada, escritório nos fundos, piscina e churrasqueira na lateral, e o 2º carro no futuro.

- **Maquete interativa:** abra o `index.html` (ou o link do GitHub Pages deste repositório).
- **Imagens das opções:** pasta `imagens/`.

Os volumes e custos são estimativas de estudo, não projeto executivo nem orçamento. Medidas e regras de recuo precisam ser confirmadas com engenheiro e Prefeitura.
