## Como usar o orçamento

1. Abra o [orçamento](https://ganseblumchen97.github.io/estudo-casa-3d/#orcamento). Ele já vem com os itens da configuração escolhida.
2. Ajuste quantidades e preços, ou use **+ Adicionar item** para incluir materiais e serviços (escolha da lista ou escreva).
3. Preencha responsável, data, BDI e observações.
4. Clique em **Gerar PDF** e escolha **Salvar como PDF**.
5. Para devolver uma versão que ainda pode ser editada, use **Salvar arquivo**; quem receber abre com **Abrir arquivo**.

O que é digitado fica salvo só no navegador de quem está usando.
